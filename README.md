Java Calculator

A menu-driven calculator built using Java.

Features

- Addition, Subtraction, Multiplication and Division
- Multiple calculations
- Calculation History
- View and Clear History
- Invalid operator handling
- Division by zero handling
- Exit option

Concepts Used

- Java Basics
- Scanner Class
- Switch Statement
- Do-While Loop
- ArrayList
- For-Each Loop
- Conditional Statements

How to Run

1. Open the project in Eclipse IDE.
2. Run "Calculator.java".
3. Select an option from the calculator menu.

Technologies Used

- Java
- Eclipse IDE
